Chat with PDFs using Hugging Face Embeddings & OpenAI
This project implements a Streamlit web app that allows users to upload PDF files, processes and indexes their content using Hugging Face embeddings with a FAISS vector store,
and enables conversational question-answering using OpenAI's GPT-3.5-turbo model.

**Features**
  1. Upload multiple PDF files
  
  2. Extract and chunk text intelligently
  
  3. Create embeddings via Hugging Face Sentence Transformers
  
  4. Store vectors in FAISS for fast similarity search
  
  5. Chat interface to ask questions about uploaded PDF contents
  
  6. Conversation history display and CSV download
